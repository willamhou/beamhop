# Beamhop Week 0 Spike

All code in this directory is **throw-away**. Goal is to validate 6 integration assumptions from spec §14 before writing any long-lived implementation code.

Spike list (see spec §14.1):
- S1: Claude Code MCP registration auto-flow
- S2: Claude Cowork connector/plugin mechanism
- S3: ChatGPT Desktop AX paste stability across versions
- S4: Chrome native messaging full round-trip
- S5: Floating window over full-screen apps / Stage Manager / multi-display
- S6: AX selected-text capture across 8 target apps

Each subdirectory contains a `notes.md` with hypothesis, method, evidence, conclusion.
Final synthesis in `results.md`. Compatibility findings in `compatibility-matrix-v0.json`.
