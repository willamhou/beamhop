## 1. 紧凑面板与焦点（优先）

- [ ] **F1 基本取消**：测试文档选中 A → 抓取 → 不点击备注框，直接输入备注 → Esc → 直接输入 `F1`。备注应能输入；Esc 后 `F1` 落回原文档，原阅读位置不变；抓取和备注仍可在 Inbox 找到。
- [ ] **F2 连续 20 次**：重复抓取 → Esc → 原文档输入一个字符，每轮间隔约 1 秒。20 次均可用，无闪退、卡住、丢输入；再用浏览器和 IDE 各测一次。
- [ ] **F3 菜单与尺寸**：点击目标行展开原生菜单并选择目标；打开菜单后 Esc 应先退出菜单，面板继续可操作。输入长备注，展开命名输入区，检查按钮/提示不截断、不跑出屏幕。
- [ ] **F4 不交接**：分别测试 `⌘0` + Enter、`⌘3` + Enter、`⌘5`。均不把来源应用换成 Beamhop；分别得到 Inbox 记录、剪贴板材料、暂存数量增长。
- [ ] **F5 主动切走**：面板打开时点击另一应用并等待 3 秒。面板关闭，焦点留在点击的应用，不突然跳回旧来源。
- [ ] **F6 替换与旧回调**：A 抓取后写备注“旧备注”，不关闭，回到来源改选 B 并再次抓取。新面板显示 B；A 的备注保存在 Inbox。新面板不被旧面板关闭事件误关。
- [ ] **F7 投递后保留目标**：选择真实 Agent，准备草稿后等待 3 秒。焦点留在目标供人工检查，不被旧来源抢回。另测投递后立即打开 Inbox，Inbox 不应被延迟回调抢走焦点。

新版设计是“来源应用保持 active，浮窗暂时拥有键盘输入”，不是先激活整个 Beamhop 再恢复。

- [ ] **S3 拦截后恢复**：切回测试文档，选中 B 再抓取。应正常成功，来源应用和文本正确。

## 3. 暂存架与批量交接（新版重点）

- [ ] **P1 暂存不打断**：A/B/C 分别抓取，每次选 `⌘3`，加备注 A/B/C，再按 `⌘5`。只增加角落数量，不自动弹出暂存架，不切换阅读位置。
- [ ] **P2 关闭与选择保持**：`⌘⇧P` 打开，选择 A 和 B；分别用 Esc、外部点击、关闭按钮收起后重开。同一运行会话内选择仍在，内容顺序正确。
- [ ] **P3 单次合并**：仅选择 A/B，目标剪贴板，点击交接（或 `⌘Enter`）。手动粘到空白测试文档：得到一个合并文本，按 A→B 排列，各有来源和备注，没有 C、没有重复。
- [ ] **P4 部分移除与原文保留**：P3 后暂存架仅移除 A/B，C 仍在；Inbox 中 A/B 原始抓取、备注和 copied 记录仍在。
- [ ] **P5 失败重试**：暂存架选择 C，选已安装但已退出的接收应用并交接。应显示失败、保留 C 和选中状态；即使另有剪贴板兜底，也不能冒充原目标成功。改选剪贴板重试成功后才移除 C。
- [ ] **P6 跨启动持久化**：再次暂存一条带备注和明确目标的素材，退出并重启。素材、备注、顺序和原目标仍在。选择状态只要求同一运行会话保持，不要求跨重启。
- [ ] **P7 不同工作隔离**：分别给两条素材命名“验收工作A”“验收工作B”，同样选剪贴板并暂存；同时选中时应提示目标意图不同并阻止合并，不能因应用相同就混投。

## 4. 目标与工作名称

- [ ] **D1 真实可用性**：目标菜单只列检测到的应用及剪贴板；没有安装的目标快捷键不能偷偷改选其他应用。退出应用不等于卸载，已安装但未运行的目标仍可能出现。
- [ ] **D2 命名与回忆**：选剪贴板 → 菜单“用名称记住” → 命名“验收任务” → 确认。下一次抓取能从最近工作选择该名称，接收应用仍是剪贴板。
- [ ] **D3 明确退出命名工作**：选某个最近工作，再从菜单直接选另一应用；应退出原工作名，成为明确的工具级选择，不暗中修改旧工作。
- [ ] **D4 换绑确认（可用时）**：选另一工具后，用命名入口输入已有工作名，使同一名称对应不同应用。首次确认只确认换绑，不能直接交接；第二次才交接。确认中再改名或换目标，先前确认不得沿用。

限制：工作名绑定的是应用，不是某个会话；“填入并检查”仍会带出接收应用，不是后台自动路由。

## 5. 草稿保护与真实 Agent（必须人工检查）

- [ ] **A1 ChatGPT 空草稿**：空白测试会话中交接，内容准备进当前输入框，**不自动发送**；Inbox 状态为 prepared/待发送，而非任务完成。
- [ ] **A2 ChatGPT 已有草稿**：输入“不要覆盖 BH1021”，不要发送，再交接。原草稿原样保留；材料复制到剪贴板并给出兜底提示。
- [ ] **A3 Kimi**：分别在空草稿和已有草稿时交接。不得自动新建会话、自动发送或覆盖草稿；无法确认空输入框时应明确复制兜底，不能误报已填入。
- [ ] **A4 Claude Code**：在专用测试终端/会话准备触发文本；不得自动执行回车。人工核对每个 capture ID 后才提交；批量交接的触发文本包含每一条选中 capture。
- [ ] **A5 失败可解释**：关闭目标窗口或退出目标后再交接。能理解哪里失败、材料在哪里、下一步怎么做；copied 不应显示成原目标已接收/已完成。
